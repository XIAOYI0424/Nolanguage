### 3.3 Java

原样运行 `Application.java`：

```
exitCode=1  phase=run  durationMs=234
stderr=<中文乱码>，解码后为：
```

原因：Java 清单 `builtin/java@1.0.0/manifest.json:343-347` 的运行步骤是 `"{toolchain}" "{file}"`，即 Java 25 单文件源码模式；引擎把源码写到临时 `main.java`，JDK 要求 public 类名与文件名一致，而该源文件的 public 类是 `Application`。此外该文件还依赖 Spring Boot 与 `com.nero.vtuber.core.*`，即使改名也会在下一步因 classpath 缺失失败。

自检用例（同一通道，最小类）：

```

```

→ Java 运行链路（工具链发现 `java` 25.0.2、源码落临时目录、编译执行、回传 stdout）是通的。

## 四、测试过程中发现的问题

| # | 问题 | 证据 | 影响 |
|---|---|---|---|
| 1 | **引擎断连崩溃**：客户端断开时写帧抛 `EPIPE`，未捕获，进程退出 | `%LOCALAPPDATA%\Nolanguage\desktop.log`：`2026-11-24T11:45:59.260Z uncaught {"name":"Error","message":"EPIPE: broken pipe, write"}`，原 PID 10388 退出 | 产品级缺陷。任何非浏览器客户端（或浏览器被强关）都可能让整个 IDE 服务退出。应把 `transport.send` 的写失败降级为"关闭该连接" |
| 2 | **Node 内置 WebSocket 握手失败**：`Origin: null` 被服务器的同源检查拒绝 | `src/net/websocket.ts:420-435`：`Origin: null` → `new URL()` 抛错 → 403；Node 24 全局 WebSocket 不支持自定义 Origin 头 | 测试工具侧约束，非产品缺陷。最终用原生 TCP 实现 RFC6455 客户端并带合法 `Origin: http://127.0.0.1:7310` 完成测试 |
| 3 | **Java 错误信息乱码** | `runOut` 中 stderr 为 GBK 字节被按 UTF-8 解码 | 影响可读性，不影响执行；中文 Windows 下所有子进程的 stderr 都有此风险 |
| 4 | **多模块 Java 项目无法直接用 `run` 消息运行** | 清单 `run.mode=template`，步骤 `"{toolchain}" "{file}"` | 需要项目级运行配置（classpath/入口类/工作目录）或走现有 fat jar；本次为遵守"不直接调用命令"的约束，未改用终端直跑 jar |

## 六、建议

1. 修复 EPIPE：在 `WsTransport.send()` / `attachClient` 的 reply 路径捕获写异常，按连接关闭处理，不要冒泡成 `uncaught`。
2. Java 多模块项目补一条"项目运行配置"路径（沿用 `runConfigs`），让 `run` 消息能带 classpath 与入口类；否则该类项目只能通过 fat jar 运行。
3. 子进程输出统一按 UTF-8 解码并加 GBK 回退，避免中文 Windows 下 stderr 乱码。

### 7.1 执行方式

```text
termExec cmd = powershell -NoProfile -ExecutionPolicy Bypass -File
               D:\15936\Documents\Nolanguage\.tmp\run-jar.ps1
```

`run-jar.ps1` 内容（位于工作区，不在 NeroSama 内）：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$p = Start-Process -FilePath java -ArgumentList @('-Dfile.encoding=UTF-8','-jar',
     'D:\15936\Documents\NeroSama\vtuber\java\app\build\libs\app-0.1.0-SNAPSHOT.jar',
     '--spring.main.web-application-type=none') -PassThru -NoNewWindow
if (-not $p.WaitForExit(25000)) { $p.Kill(); Write-Host '[probe] killed after 25s' }
exit $p.ExitCode
```

加 `--spring.main.web-application-type=none` 是为了让常驻 Web 服务跑完 `main` 后自然退出，便于取到确定退出码；`-Dfile.encoding=UTF-8` 解决中文 Windows 下日志乱码。
