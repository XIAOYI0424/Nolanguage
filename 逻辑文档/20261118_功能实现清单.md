| 套件 | 覆盖 |

| `npm test`（vitest，2 文件） | 纯逻辑：归因、解释器选择、XML、依赖解析（含 6 生态）、模板展开、路径逃逸、握手 |

| `verify:ui-dom` | DOM 级交互（jsdom） |
| `verify:ui-live` | 真浏览器（headless Edge + CDP）的编辑器与键位，缺 Edge 则 SKIP |
| `verify:arch` | 八条架构规则 + 预算 + 纯净性 + 接线 |
| `verify:docs` | live 文档路径/命令/版本、dated 文档日期、每份 md 归类 |
| `verify:langplugins` | 17 套模板按默认参数真生成一遍，断言无未解析 `{{key}}` |
| `verify:exec` | 沙箱并发、session 顺序、跨语言拒绝 |
| 其余（共 53 套） | 启动、面板、LSP、Go/Python/JS 闭环、MCP、扩展、安装器、打包 exe smoke 等 |
