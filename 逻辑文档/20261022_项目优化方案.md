# Nolanguage 当前项目优化方案（2026-10-22）

> 依据：当前工作区代码、`verify-all` 最近一次 **1380/1380 · 29 套件**、最近 5 次提交、
> 未提交的 29 文件 WIP、以及 2026-10-19～20 的桌面/弹窗/孤儿进程实测。
> 目标不是“再加功能”，而是先把**交付可信度**和**迁移门槛**补上，再谈平台深度。

---

## 0. 结论先行

当前最高杠杆的 5 件事，按顺序：

1. **先收口 WIP**：29 个文件、+2731/−252 行未提交；不先跑绿并提交，后面所有“修复”都可能建立在未验证的基线上。
2. **版本单一真相 + 自更新**：用户多次运行的是 `D:\Nolanguage` 里的旧 exe，导致“修了还是有弹窗”。必须让安装路径、版本号、构建哈希、更新提示只有一个来源。
3. **桌面运行时定调**：Tauri 原生窗口在 wry 0.57 + WebView2 143 上启动即崩（`msedge.dll`，`SubCode=0x80000003`），且无更新版本可升；0.7 正式支持 **Edge `--app`**，Tauri 只做时间盒 spike，**不交付空白窗口**。
4. **无感迁移三门槛**：解释器自动识别、`.idea/runConfigurations` 导入、PyCharm Keymap —— 这三项决定 PyCharm 用户第一分钟是否流失。
5. **阶段 11 归因引擎**：CUSUM + Welch t + Cohen's d + 二分，把“感觉变慢”变成“哪个函数 / 哪个 commit”。这是平台真正的差异化，不是再堆面板。

## 3. P0 优化方案（先做，约 2 周）

### 3.1 收口 WIP → 0.7.0（第 1 天）

**动作**
1. 逐块 review 29 文件 diff，按主题拆 3 个提交：`PyCharm 迁移能力`、`本地化插件`、`安装器/桌面`。
2. 跑 `tsc --noEmit`、`npm test`、`verify-all`、`build:exe`、`build:setup`。
3. 版本升 `0.7.0`，写 `CHANGELOG.md`（修复项 + 新增项 + 已知问题）。
4. 打 tag `v0.7.0`。

**验收**
- 全量 ≥1380 绿；`git status` 无 tracked 修改；exe/Setup 哈希记录在 CHANGELOG。
- 若 WIP 有失败：先修/回退，不带病进入下一阶段。

### 3.2 版本单一真相 + 自更新（第 2–3 天）

**现状问题**：用户安装目录、`dist`、`installer` 三份 exe 各自演化；`/health` 只返回 `appVersion`，不返回构建哈希；桌面不比较版本。

**方案**
- `/health` 增加：`build`（git sha + build time）、`exeHash`、`installId`。
- 安装器写 `install-receipt.json`：`installPath / version / sha256 / installedAt / source`。
- 启动时比较 **自身 exe 哈希** 与 **运行中服务 build**：
  - 不一致 → 提示“已安装新版本，重启生效”，并提供“立即重启”。
  - 一致 → 正常启动。
- `nlg update`：从本地文件 / https 清单读取新版本，校验 `sha256` + `trust.signature`，替换 exe 前保留 `.bak`。
- 删除“手工复制 exe”路径；安装器是唯一入口。

**验收**
- 装 0.7.0 → 替换 0.7.1 → 启动出现升级提示；不出现“旧进程 + 新窗口”混合。
- `nlg doctor` 能打印 install receipt 与哈希一致性。

### 3.3 桌面运行时定调（第 4–5 天）

**决策矩阵**

| 形态 | 独立窗口 | 依赖 | 现状 |
|---|---|---|---|
| Edge `--app` | 无地址栏/标签页，但走 Edge | 系统 Edge | **可用**，0.7 正式支持 |
| Tauri + WebView2 | 原生窗口 | wry/tauri + WebView2 | **阻塞**：wry 0.57 + WebView2 143 启动崩 |
| 系统浏览器 | 标签页 | 默认浏览器 | 仅兜底 |

**0.7 决策**
- **正式支持 Edge `--app`**：启动前预检 Edge 路径/版本、profile 锁、更新弹窗开关；Edge 缺失 → 明确提示并回退系统浏览器。
- **Tauri 标记 experimental，不交付安装包**；保留 `src-tauri` 代码与构建脚本。
- Tauri 时间盒 spike（单独分支，不阻塞 0.7）：
  1. 等 wry/tauri 新版本（当前 `cargo update` 已确认无更新）；
  2. 或做最小 WebView2 宿主复现，确认是 wry 参数还是 WebView2 143 兼容性；
  3. 验收：出现 `msedgewebview2.exe` 子进程 + 页面渲染 + 关窗回收 sidecar；三者缺一不发布。

**验收**
- `nlg doctor --desktop` 输出：Edge 路径/版本、profile 可写、上次窗口 PID、Tauri 状态（experimental）。
- 没有 Edge 的机器：启动给出可操作提示，不出现空白窗口。

### 3.4 进程生命周期 + `nlg doctor`（第 6–7 天）

**已有**：8s 关停硬超时、孤儿服务器接管、`isAlive(windowPid)` 看门狗。

**补强**
- **子进程登记表**：LSP / warm worker / extension host / script-host 统一登记，退出时按表 kill；父进程死亡检测（Windows Job Object 或 PID 轮询）。
- **端口所有权检查**：启动前确认 7310 的 owner 是自己或孤儿；不是则提示，不盲目退出。
- **单实例**：命名互斥量/锁文件，避免双击多次。
- **`nlg doctor`**：版本/哈希、安装路径、7310 owner、profile 锁、Edge/WebView2、Git、Python/Go、插件注册表、最近 20 条错误；支持 `--json`。

**验收**
- 杀 server → 窗口 8s 内关闭；杀窗口 → server 8s 内退出；孤儿 → 下次启动接管。
- `nlg doctor` 能在一屏内指出“为什么没有 UI”。

### 3.5 可观测性与发布工程（第 8–10 天）

- 统一 `desktop.log` + `server.log` + 子进程退出码；WebView2/Edge 崩溃写一条结构化记录（不只看 Crashpad）。
- 用户可见“报告问题”按钮：打包 doctor 输出 + 最近日志（脱敏）。
- **代码签名**（Authenticode）：降低 SmartScreen/杀软弹窗；CI 产出 sha256 + 签名。
- CI：`typecheck → test → verify-all → build:exe → build:setup → 静默安装 → /health smoke → artifact`。

**验收**
- 未签名 → 签名后，首次运行 SmartScreen 提示消失/降级。
- CI 全绿才允许 tag。

## 4. P1 优化方案：无感迁移（约 3–4 周）

沿用 `20261021_PyCharm无感迁移优化方案.md` 的优先级，收敛为 6 项：

| 项 | 内容 | 工期 | 验收 |
|---|---|---|---|

| P1-3 | Keymap 抽象 + PyCharm 方案 + Ctrl+F/H | 3–5 天 | 快捷键可切换/持久化；查找替换可用 |

## 5. P2 优化方案：平台深度（6 周后）

### 5.1 阶段 11 · 归因引擎（最高优先）
- **算法**：CUSUM 突变检测 → Welch t 检验 → Cohen's d 效应量 → 二分定位 commit/函数。
- **接入**：PerfSpine 指标 + 基线（SQLite 热层/JSONL 冷层）+ Git commit。
- **验收**：注入一次合成回归（某函数 sleep 增加 30%），在 N 次运行内检出，输出“函数 + commit + 置信度”，误报率可量化。

### 5.2 插件市场远程安装 + `trust.signature`
- 签名 manifest（ed25519），包 `sha256` 固定；安装前验签 + 哈希；默认拒绝未签名；信任提示；失败回滚。
- **验收**：篡改包被拒；未签名默认不可装；升级失败保留旧版。

### 5.3 阶段 12 · AI 原生
- 命令总线暴露为 MCP tools；默认只读；写/执行需确认；审计日志。
- **验收**：工具清单可枚举；每次调用有 traceId；危险操作二次确认。

### 5.4 其余
- Markdown 预览窗格 / outline（#40）。
- `verify-exec.ts`（#45）：执行平面独立套件。
- 本地化插件（WIP 的 `type: localization`）：完成 loader/校验/文档。

## 9. 不做清单（护栏）

- 不在 Node 引擎引入第三方运行时依赖；Tauri 依赖只存在于壳。
- 不在引擎里写 `if (language === 'python')`；语言差异进 manifest。
- **不在 WebView2 宿主验证通过前发布 Tauri 安装包**。
- 不新增 `spawn` 而不加 `windowsHide: true`。
- 不再手工复制 exe；安装器/更新器是唯一入口。
- 不破坏单文件自包含 HTML 与“一页一个 IPC”契约。
- 不在 P0 迁移门槛完成前继续加面板。
