1. **`profileResult` 重复 case，后半段不可达** — `src/panel/ui/client/50-runtime.js`

2. **DAP 断点在 `configurationDone` 之后才下发** — `src/dap/DapClient.ts` + `src/panel/server.ts`
   - `DapClient.start(breakpoints?)` 新增可选参数，在 `configurationDone` **之前**调用 `setBreakpoints`（adapter 收到 `configurationDone` 才启动目标）。
   - `server.ts` 把断点计算移到 `dap.start()` 前，改传 `dap.start({ file, lines })`，删除 start 后的 `setBreakpoints`。
   - 生命周期注释修正为 `initialize → launch → setBreakpoints → configurationDone`；attach 路径无参兼容。

   - `handleTerm` 新增 `cwd` 参数，`spawn` 的 `cwd` 由 `process.cwd()` 改为调用方传入的 `fs.root`（explorer 工作区根，`openFolder` 后动态跟随）。
